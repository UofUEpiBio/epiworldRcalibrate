# Archive

Earlier experiments that are **not** part of `Report_SEIR_SIR.html` (moved here on 2026-10-17):
the pretrained-model reproductions, SEIR/SIR v2-v6 models (including the reported-case models
v4-v6), the variable-length and method-comparison reports from before the noise-free models,
`All_results.html`, and their results (`archive/results/`).

The `.Rmd` files here still point to `results/...`, so to re-run one, copy it back to
`examples/` and its results folder back to `examples/results/`. The HTML reports inside the
results folders can be opened as they are.
