# Original SEIR comparison scripts

These files are preserved as the project-specific reference implementation used
for the SEIR study:

- ABC-MCMC
- ABC-SMC
- Nelder-Mead
- Differential Evolution
- five-method comparison with BiLSTM
- SLURM comparison workflow

The generic package API in `R/03_test_compare.R` is the reusable
version. These reference scripts remain useful for the exact SEIR/HPC study.
